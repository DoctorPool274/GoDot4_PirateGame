# 🏴‍☠️ GoDot4 PirateGame

Ein 2D/3D-Spieleprojekt entwickelt in Godot 4. Fokus liegt auf der Implementierung von Spielmechaniken, Input-Handling und Objektsteuerung.

---

## ✨ Features

- 🎮 **Spielmechaniken:** Bewegungs- und Steuerungslogik in Godot.
- 🏗️ **Skripting:** Objektorientierte Umsetzung der Game-Loop.
- 👾 **Engine-Integration:** Nutzung von Node-Strukturen und Szenen in Godot 4.

---

## 🛠️ Tech Stack

- **Engine:** Godot 4
- **Sprache:** GDScript / C#
